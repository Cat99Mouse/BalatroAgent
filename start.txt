BalatroLLM 启动命令

1. 先检查配置，不启动游戏、不调用模型：

uv run balatrollm config/local.yaml --dry-run

2. 正式启动自动游戏，并开启观察页面：

uv run balatrollm config/local.yaml --views

3. 启动后打开观察页面：

http://localhost:12345/views/task.html
http://localhost:12345/views/responses.html

说明：

- 需要先配置好 Balatro / BalatroBot。
- `config/local.yaml` 中需要设置模型、base_url 和 api_key。
- `--dry-run` 只显示将要执行的任务。
- `--views` 会启动 Balatro 实例、调用 LLM API，并将运行记录写入 `runs/`。
